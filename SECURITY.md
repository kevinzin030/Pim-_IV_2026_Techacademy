# Segurança

Este projeto é acadêmico e está em desenvolvimento.

## Como reportar uma vulnerabilidade

Não publique senhas, tokens, dados pessoais ou detalhes exploráveis em Issues públicas. Entre em contato diretamente com os responsáveis pelo projeto por um canal privado acordado pela equipe.

## Regras para desenvolvimento seguro

- Não versionar arquivos `.env`, credenciais ou chaves de API.
- Manter apenas `.env.example` com nomes de variáveis e valores fictícios.
- Não utilizar dados reais de estudantes em exemplos, capturas de tela ou testes.
- Validar entradas na API e verificar autorização no servidor.
- Não considerar a interface web ou mobile como substituta da autorização no backend.
