# Aplicação Mobile

Aplicação mobile a ser desenvolvida do zero. A tecnologia e o ambiente definitivos devem ser registrados aqui quando forem confirmados.

## Responsabilidades previstas

- Permitir que usuários autorizados consultem notas e frequência.
- Consumir a API do projeto.
- Exibir estados de carregamento, ausência de dados e falha de conexão.
- Proteger a sessão e não armazenar credenciais em texto puro.

## Estado atual

Estrutura documental inicial. O código da aplicação ainda será adicionado a este diretório.
