## Preservação do código

O repositório original não deve ser apagado, renomeado nem sobrescrito durante a organização do PIM IV. Antes de integrar o código neste diretório, faça uma cópia de segurança e confira o estado do Git.

A integração da aplicação existente em `web/` ainda precisa ser feita a partir de uma cópia local do repositório original. Este README é apenas um marcador de documentação; ele não substitui os arquivos da aplicação.

## Responsabilidades previstas

- Manter e evoluir as telas e funcionalidades web existentes.
- Permitir que docentes lancem notas e registrem frequência, conforme os requisitos aprovados.
- Consumir a API central quando a integração estiver implementada.
- Não armazenar segredos no código-fonte.
