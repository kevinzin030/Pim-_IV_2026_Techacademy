# site Web

## Visão geral

A aplicação Web do PIM IV foi desenvolvida do zero, com uma estrutura própria, organizada e preparada para atender aos requisitos funcionais do projeto.

O desenvolvimento independente permite maior controle sobre a arquitetura, a manutenção e a evolução das funcionalidades, sem modificar ou sobrescrever o repositório original da aplicação anterior.

## Responsabilidades

- Disponibilizar as interfaces e funcionalidades destinadas aos professores e alunos.
- Permitir que os professores lancem notas e registrem a frequência dos alunos, conforme os requisitos definidos.
- Permitir que os alunos consultem suas informações acadêmicas, notas e frequência.
- Organizar o código para facilitar a manutenção e a implementação de novas funcionalidades.
- Preparar a aplicação para integração com a API central do sistema.
- Manter a separação de responsabilidades entre HTML, CSS e JavaScript.
- Evitar o armazenamento de senhas, chaves ou outros dados sensíveis diretamente no código-fonte.

## Estrutura e desenvolvimento

A aplicação é desenvolvida de forma independente, com organização dos arquivos de estrutura, estilização e funcionalidades.

- **HTML:** estrutura e marcação das páginas.
- **CSS:** estilos visuais, layout e responsividade.
- **JavaScript:** lógica de funcionamento, interações e validações.

A integração com a API central será realizada conforme a evolução do projeto e a implementação dos serviços necessários.

## Observações

Este diretório contém a documentação referente à nova aplicação Web do PIM IV. Os arquivos e as funcionalidades devem refletir a implementação atual do projeto, sem presumir integrações ou recursos que ainda não tenham sido desenvolvidos.
