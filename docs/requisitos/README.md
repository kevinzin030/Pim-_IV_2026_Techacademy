# Requisitos do sistema

Esta pasta deverá conter os requisitos funcionais e não funcionais aprovados para o PIM IV.

## Escopo inicial confirmado

- O professor lança notas pela plataforma web.
- A frequência é registrada pela plataforma web.
- O aplicativo mobile permite consulta de notas, frequência e demais informações autorizadas.
- A API Node.js + Express integra os módulos com o banco de dados.
- O desktop é desenvolvido em C# Windows Forms.

## Antes de marcar requisitos como concluídos

Cada requisito deve possuir identificador, descrição, prioridade, responsável, critérios de aceitação e evidência de teste quando aplicável. Confirmar os requisitos finais com o manual oficial do PIM IV e com a equipe.
