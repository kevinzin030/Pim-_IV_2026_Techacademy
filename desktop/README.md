# Aplicação Desktop

Aplicação planejada em C# com Windows Forms, desenvolvida do zero para o PIM IV.

## Estado atual

Estrutura documental inicial. O projeto Windows Forms ainda será adicionado a este diretório.

## Diretrizes previstas

- Interface consistente com a identidade visual TechAcademy.
- Separação entre interface, serviços de acesso à API e modelos.
- Consultar a API para obter dados e executar operações autorizadas.
- Tratar erros de conexão e entradas inválidas sem expor informações sensíveis.

## Execução

As instruções de compilação e execução serão adicionadas após a criação da solução e a definição da versão do .NET.
