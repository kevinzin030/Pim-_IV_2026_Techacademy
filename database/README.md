# Banco de dados

Esta pasta será utilizada para armazenar:

- scripts de criação e evolução do esquema;
- dados de demonstração fictícios, se necessários;
- documentação de tabelas, relacionamentos e índices;
- instruções para preparar o banco local.

Não armazenar backups de produção, dados reais de alunos, senhas ou credenciais. A tecnologia e o esquema definitivos devem ser confirmados antes da criação de scripts de migração.
